# AI-scuola

Piccole app interattive per parlare di intelligenza artificiale in classe. Ogni attività è un singolo file HTML: niente installazioni, niente account, niente dipendenze esterne. Si apre nel browser (anche offline) e si proietta alla LIM o si usa sui dispositivi degli studenti.

## Come si usa

1. Scarica o clona il repository.
2. Apri il file `.html` dell'attività con un browser qualsiasi.

Nessun dato esce dal computer: le app non usano server né servizi esterni.

## Le attività

### Come funziona un'IA

| File | Attività | Di cosa si tratta |
|---|---|---|
| [06-macchina-che-indovina.html](06-macchina-che-indovina.html) | La macchina che indovina | Scrivi l'inizio di una frase, proponi tre parole, dai i voti e tira il dado: così un modello sceglie la parola successiva. |
| [07-chat-smemorata.html](07-chat-smemorata.html) | La chat smemorata | Una chat che risponde con frasi scritte dalla classe; la memoria è un interruttore da accendere e spegnere. |
| [08-consigliere.html](08-consigliere.html) | Il consigliere | Un'app di video che impara da ogni click: si vede la bolla dei suggerimenti che si chiude. |
